# Iban Larralde, photo et vidéo de surf

Site one-page pour un photographe surf fictif basé à Guéthary : galerie, tarifs, questions et formulaire de réservation.

- Un seul fichier, `index.html` : HTML, CSS et JS sans dépendance, police Archivo via Google Fonts.
- Version mobile dédiée : menu plein écran, barre « Réserver » fixe en bas, galerie sur 2 colonnes, swipe dans la visionneuse.
- Mode clair et sombre selon le réglage du système.

## Voir en local

```bash
npx http-server larralde-surf -p 5178
```

## Avant une mise en ligne

- Le formulaire n'envoie rien : à brancher sur Formspree, Calendly ou un backend.
- Les photos sont des images de démonstration Unsplash. Les prix et les contacts sont fictifs.
